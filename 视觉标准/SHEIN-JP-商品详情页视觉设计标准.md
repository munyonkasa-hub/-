# SHEIN JP 商品详情页视觉设计标准

来源：[《整理视觉标准》公开分享会话](https://chatgpt.com/share/6b0596ec-8160-83eb-a633-1c428eb6d213)。本文件将该会话整理的历史做法、视觉建议与验收要求转为团队共用的执行标准。商品事实、用户最新决定和获批的 Skill 2 页面目标优先；本文件不把示例商品的道具、房间或页面形式固定为通用模板。2026-11-24 用户明确选择了下述英寸两位小数与尺寸免责声明，覆盖 Skill 3 旧版的默认一位小数和笼统免责声明。

## 1. 从购买问题设计画面

每页先明确买家疑问、需要传达的可证实结论与本品证据，再选择场景、动作、对比、局部、信息图或真实照片排版。Skill 2 决定页面目标和获批页序；Skill 3 独立设计每页的空间、陈列、摄影、图文结构和日语文案；制作 Agent 按完整设计执行；质检 Agent 对照设计与成品验收。页面数默认八页，具体页序与替代形式以批准稿为准。不能把八页统一套用白底商品加文字，也不能为满足场景要求给尺寸、细节等信息页强加房间。

全套统一商品 SKU、真实结构、画幅、字体体系、辅助色、文案风格及颜色还原。逐页独立决定商品位置、镜头、景别、场景、道具、人物动作、图片与文案面积、标题位置和阅读顺序。信息区大小由实际文案与图像决定，避免大片无效留白。A/B 版应改变空间、陈列、机位、构图和信息表达；只换文案或背景颜色不构成完整视觉方案。

## 2. 画幅、字体与信息识别

| 项目 | 执行标准 |
| --- | --- |
| 主详情页 | 3:4 竖版；常用交付尺寸 1200 × 1600 px；单页独立可读 |
| SKU 规格图 | 默认 1:1；按批准的实际用途重新构图，不拉伸 |
| 日文字体 | Noto Sans JP；标题 Bold，正文 Regular；检查真实字体渲染、换行和乱码 |
| 参考字号 | 主视觉标题 44 pt、信息页标题 42 pt、正文 17 pt、尺寸 28 pt、免责声明 13 pt；按画幅和手机可读性调整，不把参考数值当固定像素模板 |
| 辅助色 | 鼠尾草绿 `#98A488` 小面积用于数字、标签、线条或正向提示；正文用深灰，文案区用独立白底 |
| 边距与层级 | 同页模块采用一致边距、对齐基准和间距；标题、正文、注释、图像和局部信息层级清楚，不重叠 |
| 无字页 | P1 与末页为完整生活场景，无标题、标签、尺寸线、图标、Logo、边框或拼贴；如用户明确改变则以最新批准稿为准 |

辅助色不覆盖真实住宅照片，也不改变商品颜色。非无字页优先把日语标题、解释性正文和局部说明置于摄影区外的独立白底信息区；文字密度由页面信息决定，不强制相同留白或文案区高度。正文要说明真实商品依据与使用动作，避免复述标题。

尺寸以已确认的厘米为依据，`in = cm ÷ 2.54`，英寸保留**两位小数**，标注线对应真实测量位置；宽、深、高、内部净空和可调节范围不能混淆。尺寸页使用以下日语免责声明，排版时逐字核查：

> ※サイズは採寸方法により、1–2cm程度の誤差が生じる場合がございます。

该句是用户选定的页面说明，不用于推定未测量的商品尺寸或功能。涉及具体 SKU 的标注仍须核实来源；详情交付文件规格及压缩上限继续执行制作 Agent 的既有规则。

## 3. 日本住宅、陈列与摄影

场景以普通日本紧凑住宅的真实生活尺度为设计基准；1K、1DK、1LDK 与年轻独居者是市场定位假设，不能当作某张参考图或评论的已验证事实。场景页应明确墙、地、门窗、主要家具及其摆位，商品与家具的高度和距离、取物或通行空间，以及前景、中景、远景的作用。商品必须有合理的摆放理由。不要用豪宅、样板间、缩小的参照家具或放大的商品制造视觉效果。

道具围绕单页使用主题选择，并能说明商品的用途或使用结果。商品内外物品的数量、体积和使用动作应符合真实容量与动线；人物是否完整出镜由功能表达决定，不能用机械伸手代替生活行为。对比页保持同一空间、机位、基础家具、物品数量和光线等主要条件一致，只改变待证明的因素；不得通过夸张脏乱或改变房间尺度制造效果。

默认中性、柔和的窗边日光和真实阴影；5200–5600 K 只是摄影白平衡的方向参考，不是模型参数实测值。白墙不泛黄、木地板不橙化、白色或奶油色商品不漂色，金属和透明材料保留真实质感。用户获批的特定时间与光线可改变场景氛围，但商品真实颜色不变。参考图只迁移空间关系、光线、配色、机位和陈列逻辑，不迁移竞品商品结构。

商品是第一视觉主体，背景提供空间参照；主视觉商品画面占比约 70–80% 仅作构图建议。通过机位、取景和背景层次调整，不拉伸商品、缩小家具或破坏透视。默认保留原始白底图可核实的拍摄角度；新视角需要足够结构资料。避免前景遮挡层数、抽屉、支架、把手、脚垫等关键部件。

## 4. 八页默认视觉节奏

下表是可调整的设计骨架，具体内容以获批 Skill 2 结构为准。摄影/视觉内容比例为建议值，不是逐页固定模板。

| 页 | 默认任务和表现 | 建议视觉占比 |
| --- | --- | --- |
| P1 | 无字真实住宅主场景；商品突出，完整空间和生活主题清楚 | 100% |
| P2 | 用真实人物行为、痛点情境或其他适合本品的证据展示核心价值；短文案解释画面 | 约 75% |
| P3 | 用商品实景和可见结构、动作、局部放大或信息模块证明不同卖点 | 约 65% |
| P4 | 可采用同条件前后对比、功能差异或另一种真实视觉证据；对比公平、变化明显 | 约 80% |
| P5 | 完整商品结构与准确 cm/in 尺寸线；白底可用，优先保证轴向和手机可读性 | 约 80% |
| P6 | 默认上方独立文案、下方 2×2 真实商品细节；同尺寸、同边距、各格不同部位，优先实拍裁切 | 约 75% |
| P7 | 展示用途不同且空间合理的真实生活场景；四宫格只是适用时的选择 | 约 85% |
| P8 | 与 P1 有视觉差异的无字完整生活场景，表现另一位置、主题或角度 | 100% |

P2、P3、P4、P7 不得退化为白底商品加说明文字；P5 不需要强制房间；P6 不得 AI 虚构材质或连接结构。安装、升降、旋转、抽拉、折叠和免安装等特殊功能按本品真实动作单独设计，优先使用本品过程实拍。缺少可靠细节时记录缺口并调整可执行方案，不生成猜测出来的结构。

## 5. 商品事实与视觉证据

用户提供的原始商品图、最新确认 SKU 与尺寸是商品外观和参数依据。锁定外形比例、层数、材料、颜色、金属件、连接方式、抽拉方向及功能部件；不得加减零件、替换材质、改变容量或让道具穿透商品。场景和商品冲突时调整场景。看不到的背面和内部结构标记未知。

Skill 3 按 Skill 10 原包回看所用案例的原始图，逐页保留样本 ID、来源链接、实际看图状态、真实可见观察、可迁移元素、不可迁移元素和本页应用方式。只有文字或缩略图时标记 `NOT_VIEWED` 或 `PARTIAL`，不能声称已完成原图视觉核验。研究结论与创意建议分开写。

## 6. Skill 3 完整脚本与制作交接

每页脚本应有下列设计信息；不适用的住宅或人物字段明确写不适用，场景页不得省略：

| 页面任务 | 必备设计信息 |
| --- | --- |
| 定位与证据 | ①页码、名称；②买家疑问；③本页结论；④视觉形式；⑤SKU 与原图依据；⑥视觉证据及应用 |
| 场景与陈列 | ⑦住宅类型与生活主题；⑧墙地门窗；⑨家具及摆位；⑩商品位置与尺度；⑪商品内外道具；⑫人物与动作 |
| 摄影与排版 | ⑬前中远景；⑭机位、角度与景别；⑮光线、阴影与白平衡；⑯日语标题与正文；⑰字体、字号、颜色与对齐；⑱图文面积 |
| 执行与保护 | ⑲商品锁定与禁项；⑳完整可执行制作指令 |

上述内容仍按 Skill 3 原有完整章节写成可读的逐页脚本，不能压成关键词或 JSON 摘要。脚本中的摄影底图、日文全文与版式执行分块逐字导出到制作清单；完整脚本、所用参考图、实拍原图及哈希一并交给制作 Agent。制作 Agent 的 Lovart 请求只发送获批的**无字摄影底图指令**和正确的商品参考图；版式由后期读取获批整页设计、文案和版式指令执行。记录实际发送的提示词与哈希，不能把仅内部读取的完整脚本冒充实际已发给 Lovart。

## 7. 成品视觉验收

质检独立查看原图、参考图、摄影底图和最终图，逐页核对商品真实性、日本住宅尺度、道具和人物动作、商品视觉重心、图文层级、日语准确性、字号与留白、尺寸标注及卖点是否由画面证明；再并排检查相邻页和整套的构图、场景、信息节奏与 SKU 一致性。问题须写页码、可见证据、归因环节及返工方向，定向修正后重新验收。

分享稿提出的 100 分诊断表可作问题排序参考：商品真实性 25、场景真实性 20、构图 20、图文版式 15、页面表达 15、全套一致性 5；不适用项重分权重，不能把分数当作取代实际看图的验收结论。

出现下列任一情况直接判为不合格：商品结构或尺寸/功能错误；无字页出现字；日语乱码或关键数据错误；应有场景证据的页面退化为白底商品加文字；违反人工批准的页面目标；核心卖点只有文案、无可见视觉证据。所有返工保留原版本和审批记录。
